# API Decor Studio: демо-макет редизайна

Кликабельный прототип нового сайта [apidesign.ru](https://apidesign.ru) на чистом HTML/CSS/JS, без сборки и зависимостей.

## Как открыть

- Двойной клик по `index.html`: всё работает локально, шрифты и картинки лежат в проекте.
- Или запустить локальный сервер: `python3 -m http.server 8080` и открыть <http://localhost:8080>.

## Что входит в демо

| Страница | Что можно проверить |
|---|---|
| `index.html`: главная | интерактивный интерьер с точками-материалами, каталог категорий, этапы работы, хиты фресок, команда, партнёрство для дизайнеров, отзывы, FAQ, форма заявки, шоурумы |
| `freski.html`: раздел каталога «Фрески» | фильтры (бренд, цвет, стиль, сюжет), сортировка, сетка 3/4 в ряд, быстрый просмотр карточки товара с галереей и заявкой на расчёт, SEO-текст, FAQ |
| `freski.html#p-523868747791` | прямая ссылка на карточку товара |
| `freski.html?brand=fresq` | каталог с предустановленным фильтром |

Все остальные разделы (обои, шторы, портфолио, политика и т. д.) открывают попап «раздела пока нет в демо».
Формы проверяют поля и показывают экран «Спасибо», но никуда не отправляются.

## Стиль

- Шрифты: Inter Tight (заголовки) и Fira Mono (текст), как у референса kov-i.studio.
- Знаки: пиксельные «галочки», квадратные маркеры в кнопках, нумерация `( 01 )`, серое «продолжение» заголовков.
- Цвета: тёплая бумага `#F3F0EA`, графит `#1C1A17`, бронзовый акцент `#A8683A` из логотипа-пчелы.
- Анимации: прелоадер и шторка между страницами, плавный скролл (Lenis), появление блоков и заголовков по словам, раскрытие фото, параллакс, счётчики, бегущая строка брендов.

## SEO и конверсия

- Семантика: один H1 на страницу, хлебные крошки, alt у всех изображений.
- Микроразметка JSON-LD: Organization, HomeGoodsStore (2 шоурума), FAQPage, BreadcrumbList, ItemList/Product.
- `canonical` указывает на текущие URL сайта (`/oboi/freski`), чтобы при запуске сохранить позиции.
- В макете стоит `noindex`, чтобы демо не конкурировало с рабочим сайтом. На продакшене убрать.
- Заявка вместо корзины: кнопки «запросить» на карточках, расчёт из карточки товара, мобильная панель «позвонить / telegram / заявка».

## Структура

```
index.html, freski.html
assets/css/style.css        все стили
assets/js/main.js           общие скрипты (меню, попапы, анимации, формы)
assets/js/catalog.js        фильтры и карточка товара
assets/js/vendor/lenis.min.js
assets/fonts/               Inter Tight, Fira Mono (woff2, кириллица)
assets/img/                 фото с текущего сайта, оптимизированные в WebP
```

Тексты, фото, команда, отзывы и товары взяты с текущего сайта apidesign.ru.
